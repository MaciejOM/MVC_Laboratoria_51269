## 1. Opis i funkcje aplikacji

**Aplikacja służy do zarządzania zadaniami domowymi, w tym dodawania, usuwania i edytowania ich.**

Aplikacja zawiera następujące funkcje:
- Wyświetlanie listy zadań,
- Dodawanie nowych zadań,
- Edycja zadań,
- Usuwanie zadań,
- Zmiana statusu zadań ("Nie rozpoczęte","W trakcie","Ukończone")
- Wyświetlanie szczegółów danego zadania.

## 2. Wymagane paczki:
**Do uruchomienia aplikacji potrzeba:**
- Visual Studio z zainstalowanym frameworkiem ASP.NET MVC,

## 3. Instrukcja obsługi

1. Otwórz Rozwiązanie aplikacji w Visual Studio,
2. Uruchom Aplikację (F5 lub "Debuguj > Rozpocznij debugowanie"),
3. Aplikacja teraz działa pod portem "https://localhost:7279/" (Lub innym portem w zależności, jaki zostanie przydzielony),
4. Teraz aplikacja będzie działać, dopóki nie wyłączysz Visual Studio.
